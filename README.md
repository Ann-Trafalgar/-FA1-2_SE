# NetQuest - Software Engineering Reviewer

A responsive quiz website containing 40 Software Engineering questions across
FA1 through FA4, with separate assessment cards. The combined reviewer includes
all 90 questions. It also
includes a 50-question bank imported from `walalang.txt`: 25 multiple choice,
15 true or false, and 10 typed identification questions. Identification answers
ignore capitalization and extra spaces.

The site follows the layout and behavior of the existing `networking reviewer`
project, including saved progress, question and choice shuffling, flags, instant
feedback, dark mode, sound, scoring, question navigation, and missed-question
review.
